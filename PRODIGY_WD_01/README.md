Interactive Navigation Menu

A simple front-end project focused on creating a modern and responsive navigation experience. The navigation bar reacts to scrolling, highlights the section currently in view, and adapts seamlessly across desktop and mobile devices.

The goal of this project was to practice building interactive user interface components using vanilla JavaScript while maintaining clean design principles and responsive behavior.

Features
Responsive navigation bar for desktop and mobile screens
Smooth scrolling between sections
Active menu item highlighting based on the section currently visible
Navigation style changes when the user scrolls
Mobile slide-out menu for smaller devices
Modern UI built with Tailwind CSS
Lightweight implementation with no external JavaScript frameworks
Built With
HTML5
JavaScript (ES6+)
Tailwind CSS
Google Fonts (Outfit)
