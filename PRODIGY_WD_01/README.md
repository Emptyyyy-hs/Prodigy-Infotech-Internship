# Interactive Navigation Menu

A modern, responsive navigation website built with HTML, JavaScript, and Tailwind CSS.

## Features

- Responsive Navigation: Optimized for desktop and mobile devices.
- Active Section Highlighting: Automatically highlights the current section while scrolling.
- Dynamic Navbar Effects: Navigation bar updates its appearance based on scroll position.
- Smooth Scrolling: Seamless navigation between page sections.
- Mobile Menu Support: Full-screen mobile navigation drawer for smaller screens.
- Modern Design: Clean layout, smooth animations, and professional UI components.
- Lightweight Implementation: Built without heavy frameworks or backend services.

## Technical Specifications

- Language: HTML5, JavaScript (ES6+)
- Styling: Tailwind CSS
- Fonts: Google Fonts (Outfit)
- Architecture: Single-Page Navigation Layout
- Browser Support: Chrome, Firefox, Edge, Safari

## How to Run

Open `index.html` in any modern web browser.

The project is completely client-side and does not require:

- A backend server
- A database
- Authentication services
- API keys or environment variables

## Core Functionality
- Scroll event listeners for navbar behavior
- Intersection Observer API for active section tracking
- Responsive navigation menu for mobile devices
- Smooth scrolling and CSS transitions for improved user experience
