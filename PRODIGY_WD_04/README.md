# Personal Portfolio Website

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS. Designed to showcase projects, technical skills, and professional experience through an interactive and visually engaging user interface.

## Features

- Responsive Design: Optimized for desktop, tablet, and mobile devices.
- Interactive Navigation: Smooth scrolling and section-based navigation.
- Professional Hero Section: Clean introduction with personal branding.
- About Section: Highlights background, interests, and goals.
- Skills Showcase: Displays technical skills and core competencies.
- Project Gallery: Dedicated section for featured projects and achievements.
- AI Project Highlights: Includes specialized AI and development projects.
- Contact Section: Easy access for networking and collaboration opportunities.
- Modern UI: Clean design with smooth animations and transitions.

## Technical Specifications

- Language: TypeScript / JavaScript (ES6+)
- Framework: React
- Styling: Tailwind CSS
- Architecture: Component-Based Design
- Build Tool: Vite
- Deployment Ready: Yes

## How to Run

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
